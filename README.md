# CSDC100 HTML Project: Artist Fan Page

A 5-page fan website about my favorite artist, **Chappell Roan**, built with HTML and CSS for my CSDC100 class in my first semester of college.

> **Note:** This was one of my first projects and my first time using GitHub, so the files are all in one folder instead of being organized into subfolders. I've left it as it was to show where I started.

## About the Assignment

The assignment was to build a 5-page website about a favorite topic, such as a game or an artist. I chose an artist.

## Pages

1. **Home** (`index.html`): landing page and navigation
2. **Biography** (`biography.html`): background on the artist
3. **Discography** (`discography.html`): albums and releases
4. **Shop**: a link to the artist's official online store
5. **Subscribe** (`subscribe.html`): sign-up page

Social media icons (Facebook, Instagram, Spotify, TikTok, X, YouTube) link out from the pages, and `style.css` styles the whole site.

## Built With

- **HTML5**: page structure
- **CSS3**: layout and styling (shared `style.css`)

## Viewing the Project

1. Clone the repository
   ```bash
   git clone https://github.com/rinzzze-d/CSDC100-HTML-FAV.git
   ```
2. Open `index.html` in your browser.
